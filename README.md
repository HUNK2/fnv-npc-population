# Lived-in Mojave + Mojave Caravan Company

A Fallout: New Vegas mod in two parts, built in the open:

- **Lived-in towns core**: more townspeople who belong where they live, with daily routines and
  reactions to the player's choices. Goodsprings first.
- **Mojave Caravan Company** (add-on): found and run a trading company from a terminal. Routes,
  goods and production chains, staff and managers, a rival (the Crimson Caravan), the NCR as the
  law, and a dodgy side.

Status: design done, building milestone M0 (live proofs of the engine features the design relies on).

- Build workflow: [docs/plans/2026-11-26-build-workflow.md](docs/plans/2026-11-26-build-workflow.md)
- Research: [research/](research/) (engine catalogue of NPC code, business research, design swarm reports)

Requires (planned): xNVSE, JIP LN NVSE, JohnnyGuitar NVSE.

No game files and no decompiled game code are in this repository. MIT licence.
